# Сайт мастерской — пакет для разработки

Сайт мебельной мастерской (село Архангельское, Ульяновская область): приём заявок на работу
и местная поисковая выдача.

## Как этим пользоваться

1. Распакуйте папку.
2. Откройте `design/index.html` в браузере — посмотрите прототип.
3. Откройте `PROMPT.md`, скопируйте текст ниже разделителя в чат с Claude Code (в этой же папке).
4. Claude Code прочитает `SPEC.md` и два репозитория, предложит план — подтвердите и работайте.

## Файлы

| Файл | Что это |
|---|---|
| `PROMPT.md` | Готовый промт для Claude Code |
| `SPEC.md` | Описание всех страниц, компонентов, токенов и поведения |
| `design/` | Прототип на HTML/CSS/JS — дизайн-референс, не продакшен-код |
| `tokens-detal73.css` | Целевая палитра и типографика |
| `DEPLOY.md` | Как получить постоянную ссылку на Vercel |
| `design-system-readme.md` | Дизайн-система мастерской: тон, правила копирайта, компоненты |

`model3d/` (файлы 3D-модели) скачивается отдельной папкой — положите её внутрь `design/`,
рядом с `masterskaya-3d.html`.

## Что здесь главное

**Визуальный ориентир** — detal-beta.vercel.app, то есть репозиторий
`elenaisanewleet/furniture-site`. Оттуда берётся оформление: палитра, шрифты, чертежи,
угловые метки, движение. Содержание оттуда не берётся — оно про другую мастерскую.

**Содержание** — репозиторий `elenaisanewleet/furniture-detal`, папка `ui_kits/master-site`
(она же скопирована в `design/`): услуги, станки, определитель детали, форма заявки.

**Что осталось доделать:** серверный номер заявки, отправка в Telegram-бота, загрузка голосового
файла, реальный домен, локальные шрифты, тёмная тема.
